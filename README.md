# falling-sand-game  
A "sand" game, inspired by the videos from the youtube series [coding adventures](https://www.youtube.com/watch?v=kOkfC5fLfgE&list=PLFt_AvWsXl0ehjAfLFsp1PGaatzAwo0uK), made with python  

### Observations:  
- The game uses pygame, you need it installed to run the game
- Run the game with: python3 code/game-vx.py

### How to play:
- Left-click to release sand
- Right-click to clear the sand
- Press middle-mouse button to go back to the "menu"
